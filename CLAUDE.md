# CLAUDE.md

Static site for boraborabound.com, served by GitHub Pages from the repo root of
`main`. Hand-written HTML, CSS and JS plus a Python generator. There's no framework
and no runtime npm dependency. [README.md](README.md) covers how to work on the
site, [STATE.md](STATE.md) where things stand, and [PLAN.md](PLAN.md) what's next.

## Rules

- **Never hand-edit the root `*.html`.** They're generated, and each one starts
  with a `GENERATED by tools/build.py` banner. Edit content in `pages/*.html` and
  shared parts (head, nav, footer, JSON-LD, images) in `tools/build.py`, then run
  `python3 tools/build.py` and commit the generated output with your change. CI
  fails if the committed HTML doesn't match the build.
- **Don't weaken the indexability guards.** `verify_indexability()` in
  `tools/build.py` and the robots/`STAGING` check stop a `noindex` from reaching
  production, where it would hide the site from search with no visible symptom.
- **Photos go through the `IMAGES` table** in `tools/build.py`, keyed by slot
  (`IMG_CARD_HONEYMOON`), with URL and alt text together. Fragments reference
  them as `{{IMG_…}}` and `{{IMG_…_ALT}}`. An unknown `{{TOKEN}}` fails the build.
- **Vendored libraries** (Lenis, GSAP) live in `assets/js/vendor/`. Don't swap
  them for CDN links.
- `tools/set-domain.sh staging|production` rewrites the domain in ~40 places.
  Only run it when asked.

## Commands

```bash
python3 tools/build.py                     # regenerate root HTML, sitemap, robots, redirects
python3 -m http.server 4173                # preview at http://localhost:4173/
cd tools/audit && npm ci                   # once, for the detectors
node audit.mjs                             # the six rendered-page detectors (as in CI)
node contrast.mjs                          # colour contrast, light and dark
```

Run the build and the audit before opening a PR. CI (`.github/workflows/checks.yml`)
runs the same three checks: build, HTML-in-sync, detectors.

## Local AI tooling

`tools/ai-setup/` installs OmniRoute, Headroom and claude-mem on your own machine
and adds a `claude-routed` launcher. None of it runs in cloud sessions. Keep
proxy URLs and API keys out of `.claude/settings.json`.
