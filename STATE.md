### The staging posture is deliberate

The test site is **fully blocked from search**, on purpose. An indexable second
copy of the brand would compete with the live site for its own terms.

- `CNAME` → `test.boraborabound.com`
- `robots.txt` → `User-agent: * / Disallow: /`
- Every page carries `<meta name="robots" content="noindex, nofollow">`
- All canonicals, `og:url` and schema `@id`s point at the test subdomain

Three locks, any one of which would be enough. All three flip together via
`./tools/set-domain.sh production`. **Do not hand-edit the domain** — it appears
in roughly forty places.

## What exists

**20 real pages**, 7 redirect stubs, ~12,700 words of body copy.

| Section | Pages |
| --- | --- |
| Core | Home, Ways to Travel, How I Work, About, Reviews, Contact, Refer |
| Services | Cruises, All-Inclusive Resorts, Small Group Tours, Honeymoons & Romance, LGBTQ+ Travel |
| Journal | Index + 5 posts |
| Utility | Terms (`noindex, follow`), 404 |

The offer is organised by **how** you travel rather than where — matching the
shift in focus to cruises, all-inclusive resorts, and small group tours.

### Architecture

No build step in the browser sense. Content lives in `pages/*.html` as bare
fragments; `tools/build.py` generates the committed HTML that Pages serves —
head metadata, nav, footer, analytics, JSON-LD, `sitemap.xml`, `robots.txt`, and
the redirect stubs.

**Never hand-edit the generated `*.html` in the repo root.** Each starts with a
`GENERATED by tools/build.py` comment.

### Structured data

19 schema types across the site: `TravelAgency`, `Person`, `WebSite`,
`Service` ×5, `FAQPage` (8 questions), `Blog` + `BlogPosting` ×5, `Review` ×3,
`ContactPage`, `ContactPoint`, `BreadcrumbList` ×17, `ItemList`.

The `FAQPage` block is **parsed out of the visible page at build time**, not
hand-maintained — a hand-synced copy had already drifted to 6 entries against 8
on the page, which is a Google policy problem, not just untidiness.

### Conversion tracking

30 distinct CTA locations carry `data-cta="<location>"`. A click fires a GA4
`generate_lead` event and a Meta Pixel `Lead` event tagged with its location, so
it will be possible to tell which page produces consultations. **Currently inert
— the IDs are not set.** See PLAN.

## Brand

Per `BBB Brand Guidelines.pdf` and the Canva kit, both in Drive.

**Colour:** `#4622a2` purple (primary) · `#d0356a` rose (CTA) · `#f09839` orange
· `#4aa4a6` teal · `#f6cfee` pink · `#76efe1` aqua, plus the secondary
neutrals. Every text/ground pair passes WCAG AA.

**Type:** Bebas Neue for display (real, loaded). **Poppins substitutes for
Evolve Sans** and **Sacramento for Jonathan Signature** — both originals are
commercial, absent from Google Fonts, and absent from the Drive Fonts folder, so
they cannot be self-hosted from what exists. Both sit *behind* the real faces in
the stack, so licensing either one makes it take over automatically.

**Logo:** the real BB monogram in header and footer. Favicons, apple-touch-icon,
PWA icons and the Open Graph card are all generated from it on brand purple.

## Bugs found and fixed along the way

None of these were in the audit.

- **The mobile menu was fundamentally broken.** The header uses
  `backdrop-filter`, which — like a transform — makes it the containing block
  for its own `position: fixed` children. The full-height slide-in panel
  collapsed to the header's own 60px box and spilled its links across the hero.
  The same bug left a visible sliver of the closed panel at the right edge of
  every phone. Rebuilt as a dropdown anchored under the floating pill.
- **The primary CTA was hidden below 720px.** `.nav-cta .btn { display: none }`
  meant "Get Started" vanished entirely on mobile.
- **Six of nine H1s carried no target keyword** — a gap introduced when the
  service pages were first written.
- **The FAQ schema had drifted** from the visible page. Now generated from it.
- Hero CTA collided with the scroll cue at 1280×800; nav wrapped between
  721–1180px; sticky-header handler fought the static `is-scrolled` class; the
  mobile menu had no `aria-expanded` and no Escape handling; redirect stub
  titles emitted a raw `&`. A skip-to-content link was added.
- **38 British spellings and idioms** — wrong for a US advisor. Fixed
  (`programme`, `queue`, `car park`, `holiday`, `travelling`, `sceptical`,
  `colour`, `centre`, `lifts`, `towards`, `mum`).

**Nobody has seen the deployed site render.** The build environment's egress
proxy blocks `test.boraborabound.com`, `boraborabound.com` and
`northbound-house.github.io`. GitHub reports the Pages build succeeded and every
file is confirmed present on `main`, but the rendered page at that domain has
not been looked at.

Two things render for the first time there, because they were blocked locally
too: **Google Fonts** (Bebas Neue, Poppins, Sacramento) and the **hotlinked
Unsplash scenery**. If anything looks wrong, start with those.

The same block is why the live site's analytics IDs and photography could not be
read directly.
